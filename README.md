# about the app:
a minimal weekly scheduling app for viewing the classes schedule for a week
also able to adding & removing classes
using maven, JPA/hibernate, tomcat

# start the app:
1. configure the persistence.xml based on your database
2. run the Main.main() once to create the tables
3. start the app server
